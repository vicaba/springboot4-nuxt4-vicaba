# Spring Boot 4 and Nuxt 4 Starter Template

This project uses Kotlin with Java 25 for the backend (Spring MVC) and Nuxt 4 with SSG (static site generation) mode for the frontend.
Both components are packaged and deployed using Docker.

## Backend

- Kotlin (Java 25)
- Spring Boot 4 (Web MVC)

## Frontend

- Nuxt 4 (SSG mode)

## Development Mode (Hot Reload)

To work with active hot reloading on both the frontend and backend:

1. **Start the Backend**:
   Run the Spring Boot application with the `dev` profile. Spring Boot DevTools is active:

   ```bash
   ./gradlew bootRun --args='--spring.profiles.active=dev'
   ```

   In another terminal, run `./gradlew compileKotlin -t`, this will enable hot reload and `bootRun` will pick the changes.

2. **Start the Frontend**:
   Run the Nuxt dev server. Any API calls to `/api/**` are automatically proxied to port 18080 via Nitro's dev proxy:
   ```bash
   cd frontend
   npx nuxi prepare # Creates type information for the IDE and Nuxt 4. Language server might need to be restarted.
   npm ci
   npm run dev
   ```
   _Open
   [http://localhost:3000](http://localhost:3000) (or the port specified by Nuxt)._

## Deployment in production

This project is intended to be deployed using Docker.
Docker containers can be built for both the backend and frontend components and then deployed using container orchestration platforms like Kubernetes or Docker Compose.
The Spring Boot server serves the frontend files generated by Nuxt in SSG mode, enabling seamless integration of the backend and frontend components.
